AI Meeting Assistant
A complete, free AI-powered tool to transcribe, summarize, and chat with your meeting recordings or YouTube videos.

🚀 Features
Transcription: Uses OpenAI Whisper for English and Sarvam AI for Hindi/Hinglish.
Summarization: Extracts bullet-point summaries, action items, and key decisions using Mistral AI.
RAG Chat: Engage in Q&A with your meeting data using ChromaDB and LangChain.
Export: Generate reports in PDF or TXT format.
UI: Simple and intuitive dashboard built with Streamlit.
🛠 Tech Stack
Language: Python
Transcription: OpenAI Whisper, Sarvam AI
LLM: Mistral AI
Framework: LangChain (LCEL)
Vector Database: ChromaDB
UI: Streamlit
